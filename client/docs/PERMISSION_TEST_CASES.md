# 账号权限管理功能 - 功能检查项与测试用例

## 功能检查项

### 1. 数据库表结构
- [ ] `user_permissions` 表已创建
- [ ] 包含字段：id, user_id, module_name, permissions (JSONB), created_at, updated_at
- [ ] 唯一索引：user_id + module_name
- [ ] 索引：user_id, module_name
- [ ] 更新时间触发器已创建

### 2. 后端 API
- [ ] GET /api/v1/permissions/user/:userId - 获取用户权限
- [ ] GET /api/v1/permissions/modules - 获取所有模块权限配置
- [ ] POST /api/v1/permissions - 保存权限
- [ ] PUT /api/v1/permissions/:userId - 更新权限
- [ ] DELETE /api/v1/permissions/:userId - 删除权限

### 3. 前端功能
- [ ] 权限配置页面（permission-config）
  - [ ] 显示所有可配置模块
  - [ ] 每个模块有4个权限开关（查看、编辑、新增、删除）
  - [ ] 支持切换开关
  - [ ] 保存按钮
  - [ ] 重置按钮

- [ ] 账号管理页面（users-management）
  - [ ] 显示账号列表
  - [ ] 权限管理按钮
  - [ ] 跳转到权限配置页面

- [ ] 权限控制 Hook（usePermissions）
  - [ ] 获取当前用户权限
  - [ ] 检查特定权限
  - [ ] 支持跨平台（Web + 移动端）
  - [ ] 管理员绕过权限检查

### 4. 集成到各模块
- [ ] 客户管理（customers）
- [ ] 合同管理（contracts）
- [ ] 设备管理（devices）
- [ ] 工单管理（work-orders）
- [ ] 会议纪要（meeting-minutes）
- [ ] 文件管理（files）
- [ ] 知识库（knowledge）

每个模块需要：
- [ ] 检查查看权限
- [ ] 根据权限显示/隐藏新增按钮
- [ ] 根据权限显示/隐藏编辑按钮
- [ ] 根据权限显示/隐藏删除按钮

## 完整测试用例

### 测试场景 1：权限配置功能

#### 用例 1.1：首次配置权限
**前置条件**：
- 使用管理员账号登录
- 用户没有任何权限配置

**操作步骤**：
1. 进入账号管理页面
2. 点击某个用户的"权限管理"按钮
3. 进入权限配置页面

**预期结果**：
- 显示所有可配置的模块（客户管理、合同管理、设备管理等7个）
- 所有权限开关默认为关闭状态
- 可以切换各个权限开关
- 保存按钮可用

---

#### 用例 1.2：保存权限配置
**前置条件**：
- 已进入权限配置页面
- 已配置部分权限

**操作步骤**：
1. 为某些模块开启权限（查看、编辑等）
2. 点击"保存"按钮

**预期结果**：
- 显示保存成功提示
- 权限已保存到数据库
- 可以在权限列表中看到新配置的权限

---

#### 用例 1.3：更新权限配置
**前置条件**：
- 用户已有部分权限配置
- 已进入权限配置页面

**操作步骤**：
1. 修改某些模块的权限设置
2. 点击"保存"按钮

**预期结果**：
- 显示保存成功提示
- 权限已更新
- 旧权限被覆盖

---

#### 用例 1.4：重置权限配置
**前置条件**：
- 已进入权限配置页面
- 已配置了权限

**操作步骤**：
1. 修改权限开关
2. 点击"重置"按钮

**预期结果**：
- 所有权限开关恢复到保存前的状态
- 不会保存当前修改

---

### 测试场景 2：权限控制功能

#### 用例 2.1：无查看权限
**前置条件**：
- 用户A没有客户管理的查看权限
- 用户A已登录

**操作步骤**：
1. 用户A尝试访问客户管理页面

**预期结果**：
- 显示"无权限访问此页面"提示
- 无法查看任何客户数据

---

#### 用例 2.2：有查看权限，无编辑权限
**前置条件**：
- 用户A有客户管理的查看权限
- 用户A没有客户管理的编辑权限

**操作步骤**：
1. 用户A进入客户管理页面
2. 点击某个客户

**预期结果**：
- 可以查看客户详情
- 编辑按钮不显示
- 无法修改客户信息

---

#### 用例 2.3：有查看和编辑权限，无删除权限
**前置条件**：
- 用户A有客户管理的查看和编辑权限
- 用户A没有客户管理的删除权限

**操作步骤**：
1. 用户A进入客户管理页面
2. 查看客户列表
3. 尝试删除客户

**预期结果**：
- 可以查看客户列表
- 可以编辑客户
- 删除按钮不显示
- 无法删除客户

---

#### 用例 2.4：有全部权限
**前置条件**：
- 用户A有客户管理的全部权限（查看、编辑、新增、删除）

**操作步骤**：
1. 用户A进入客户管理页面

**预期结果**：
- 可以查看客户列表
- 新增按钮显示
- 编辑按钮显示
- 删除按钮显示
- 可以执行所有操作

### 测试场景 4：异常权限处理

#### 用例 4.1：未登录用户访问
**前置条件**：
- 用户未登录

**操作步骤**：
1. 直接访问客户管理页面

**预期结果**：
- 自动跳转到登录页面
- 显示提示信息

---

#### 用例 4.2：权限配置冲突
**前置条件**：
- 同一用户对同一模块多次保存权限

**操作步骤**：
1. 为用户A配置客户管理权限
2. 保存
3. 再次修改客户管理权限
4. 保存

**预期结果**：
- 第二次保存成功
- 使用最新的权限配置
- 旧权限被覆盖

---

#### 用例 4.3：删除用户后权限清理
**前置条件**：
- 用户A有权限配置
- 删除用户A

**操作步骤**：
1. 删除用户A账号

**预期结果**：
- 用户A被删除
- 用户A的所有权限配置自动删除（ON DELETE CASCADE）

---

#### 用例 4.4：重复保存权限
**前置条件**：
- 已进入权限配置页面
- 已配置权限

**操作步骤**：
1. 不做任何修改
2. 多次点击"保存"按钮

**预期结果**：
- 每次都显示保存成功
- 数据库中的权限数据保持一致
- 不会产生重复数据

---
